# Food Talk India

A food experiences platform bringing people together around food, drinks, and culture.

## Overview

Food Talk India curates experiences celebrating the people, places, and ideas shaping modern culinary culture. This application is built with modern Next.js and Tailwind CSS, featuring high-impact visual storytelling.

### Key Highlights
- **Hero Video Experience**:
  - **Desktop**: 3-panel split triptych displaying three vertical reel videos simultaneously in real-time.
  - **Mobile**: Full-screen vertical reel slider with sequential playback, swipe gestures, and segmented progress indicators.
  - **Interactive Audio**: Independent sound toggle for each video experience.
- **Brand Experiences**: Past experiences, Serious Eaters Club showcases, brand partnerships, and newsletter subscriptions.
- **Fast & Optimized**: Video assets optimized and compressed for fast web delivery with H.264 `faststart`.

## Tech Stack
- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **UI & Styling**: [React](https://react.dev/), [Tailwind CSS](https://tailwindcss.com/)
- **Icons & Assets**: Custom SVG icons, optimized media assets

## Getting Started

First, install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Building for Production

```bash
npm run build
npm run start
```
